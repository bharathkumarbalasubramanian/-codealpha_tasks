# Task 2: Hotel Reservation System

Full-Stack Hotel Reservation System in Java supporting Web UI, REST API, Swing GUI, and Console CLI interfaces with JSON file persistence.

## 📁 Features & Interfaces
- **Web UI & REST API:** Embedded HTTP Server running on `http://localhost:8080`
- **Desktop Swing GUI:** Visual management application for rooms and bookings
- **Console CLI:** Interactive command line interface
- **JSON Data Persistence:** Fast, lightweight, zero-dependency storage

## 🚀 How to Run

### 1. Build the System
Run the build script to compile all Java source files into `out/`:
```cmd
build.bat
```

### 2. Run Applications
- **Web Interface:**
  ```cmd
  run_web.bat
  ```
  Then open `http://localhost:8080` in your web browser.

- **Desktop GUI:**
  ```cmd
  run_gui.bat
  ```

- **Console CLI:**
  ```cmd
  run_cli.bat
  ```
