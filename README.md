## 🚀 How to Run Tasks

### Task 1: Student Grade Tracker
Navigate to the `Task_1_Student_Grade_Tracker` directory:

```bash
cd Task_1_Student_Grade_Tracker

# Run Java Swing GUI Application
javac StudentGradeTracker.java
java StudentGradeTracker

# Or open Web Interface in browser
start index.html
```

### Task 2: Hotel Reservation System
Navigate to the `Task_2_Hotel_Reservation_System` directory:

```bash
cd Task_2_Hotel_Reservation_System

# Compile system
build.bat

# Launch Web Server & UI (http://localhost:8080)
run_web.bat
```

### Task 3: Artificial Intelligence Chatbot
Navigate to the `Task_3_AI_Chatbot` directory:

```bash
cd Task_3_AI_Chatbot

# Compile system
build.bat

# Launch Web Server & UI (http://localhost:8080)
run_web.bat

# Or Launch Desktop Java Swing GUI
run_swing.bat
```
